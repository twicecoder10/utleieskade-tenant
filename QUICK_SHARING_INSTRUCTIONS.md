# Quick Sharing Instructions

## 🚀 Fastest Way to Share Your App

### Android (APK) - 5 Minutes

1. **Download APK**
   - Go to: https://expo.dev/accounts/twice_coder/projects/utleieskade-mobile/builds
   - Find build `31cd266c-0a65-4879-b460-a5921ed2ac84`
   - Click "Download"

2. **Upload to Google Drive**
   - Upload the `.apk` file
   - Right-click → "Get link"
   - Set to "Anyone with the link"

3. **Share the Link**
   ```
   Download Utleieskade Tenant App:
   [Your Google Drive link]
   
   Install: Settings → Security → Enable "Install from unknown sources" → Open file
   ```

### iOS (TestFlight) - 10 Minutes

1. **Build iOS** (if not done):
   ```bash
   eas build --platform ios --profile production
   ```

2. **Submit to TestFlight**:
   ```bash
   eas submit --platform ios
   ```

3. **Add Testers**:
   - Go to: https://appstoreconnect.apple.com/apps/6756213906/testflight/ios
   - Add tester emails
   - They receive invitation
