# Test Login Credentials

## Default Test User (After Running Seeder)

### Admin User
- **Email**: `mail@mail.com`
- **Password**: `password123`
- **User Type**: `admin`
- **Login Endpoint**: `POST /users/login/admin`

### Tenant Users

After running the database seeder, tenant users are created with:
- **Password**: `password123` (for all seeded users)
- **Email**: Generated by faker (random emails)

To find tenant emails, check the seeder output or database.

## How to Get Tenant Credentials

### Option 1: Check Seeder Output
When you run `npm run seed-db`, it will output the created users. Look for tenant emails.

### Option 2: Query Database
```sql
SELECT "userEmail", "userFirstName", "userLastName", "userType"
FROM "User"
WHERE "userType" = 'tenant'
LIMIT 5;
```

### Option 3: Create Your Own Tenant User

**Via Registration in Mobile App:**
1. Open the tenant mobile app
2. Go to Sign Up
3. Fill in:
   - Full Name
   - Phone Number
   - Email (your email)
   - Password (choose your password)
   - Select Role: Tenant
   - Accept Terms of Service
4. Complete registration

**Via API:**
```bash
curl -X POST http://localhost:3000/users/register \
  -H "Content-Type: application/json" \
  -d '{
    "userFirstName": "Test",
    "userLastName": "Tenant",
    "userEmail": "tenant@test.com",
    "userPassword": "password123",
    "userPhone": "+47 123 45 678",
    "userType": "tenant"
  }'
```

## Login Endpoint

For tenant mobile app:
```
POST http://localhost:3000/users/login/tenant
```

Request Body:
```json
{
  "userEmail": "your-email@example.com",
  "userPassword": "password123"
}
```

## Create Test Tenant User

If you need a specific test tenant, you can create one via API:

```bash
curl -X POST http://localhost:3000/users/register \
  -H "Content-Type: application/json" \
  -d '{
    "userFirstName": "Test",
    "userLastName": "User",
    "userEmail": "test.tenant@example.com",
    "userPassword": "password123",
    "userPhone": "+47 123 45 678",
    "userType": "tenant"
  }'
```

Then login with:
- **Email**: `test.tenant@example.com`
- **Password**: `password123`

## Notes

- All seeded users have password: `password123`
- Email matching is case-insensitive
- Password is case-sensitive
- Make sure backend is running on port 3000
- Make sure database is seeded: `npm run seed-db` in `api` folder
